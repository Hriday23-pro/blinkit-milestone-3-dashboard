# Blinkit | Delivery Performance & Operational Analytics

## Business Analyst Portfolio Project

An interactive case study exploring delivery delays, operational performance, and customer experience using Blinkit-style quick-commerce data.

## Live Dashboard

https://hriday23-pro.github.io/blinkit-milestone-3-dashboard/

## Project Highlights

- Analysis of 1,500 orders across 20 stores
- Delivery performance and delay analysis
- Store, rider, and customer insights
- Root-cause analysis and operational recommendations

## Tools & Methods

Excel, KPI Analysis, Data Validation, HTML, CSS, JavaScript

## About

Developed as part of the NextLeap Business Analyst Fellowship — Milestone 3.

Independent educational case study; not an official Blinkit report.
